# greenbars releases

Signed builds of the greenbars Firefox add-on. This repo only holds the signed `.xpi` files (on the Releases page) and `updates.json`, which installed copies check for updates.

## Install

1. Open the latest release on the [Releases page](https://github.com/bacar/greenbars-releases/releases/latest).
2. Click the `.xpi` file. Firefox asks whether to add greenbars; click **Add**.

Firefox then keeps it up to date automatically.
